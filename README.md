
# Simple CV/Resume Card

## About the Project
A clean and responsive personal CV/Resume webpage developed using HTML, CSS, and JavaScript to showcase personal details, education, technical skills, projects, certifications, and contact information.

## Features
- Personal information
- Education details
- Technical skills
- Academic projects
- Certifications
- Contact information
- Responsive design
- Dark and light mode
- Download/Print Resume option

## Technologies Used
- HTML5
- CSS3
- JavaScript


## Project Structure

```text
Simple-CV-Resume-Card/
│
├── index.html
├── style.css
├── script.js
├── README.md
│
└── screenshots/
```


## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. View the resume in your browser.
